# Veille Techno : podcast privé

Flux RSS : https://ziryabus.github.io/veille-podcast/feed.xml

Pour l'écouter sur iPhone, ouvrez l'appli Podcasts, puis Bibliothèque → ⋯ → « Suivre un podcast par URL », et collez l'adresse ci-dessus.

Les épisodes sont générés et publiés automatiquement par l'agent de veille (Claude). Vous n'avez rien à maintenir.
